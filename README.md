# Electrotech

Astro website for Electrotech Electrical Services, the electrician listed at 5 Miller Road, Bedford, MK42 9FS.

The phone number is 01234 325435. That matches the Google listing at https://maps.app.goo.gl/2bwg1u64MmmpH95QA.

## Run it

```bash
npm install
npm run dev
```

Build the static site with:

```bash
SITE_URL=https://your-domain.example npm run build
npm run preview
```

`SITE_URL` sets the canonical links, Open Graph URLs, and the sitemap. Set it to the real domain before you publish. If you leave it unset, the build uses `https://electrotech-uk.com`, which was the firm’s old web address.

## What is on the site

- Home, about, services, projects, reviews, areas, contact, and privacy
- Service pages for the work Electrotech has actually advertised
- Local pages for Bedford, Kempston, Shortstown, Wixams, Ampthill, and Flitwick
- The Google review from DK Brawn, dated 29 March 2013, kept word for word
- Customer comments from Electrotech’s own old website, with the names and spellings they published
- `robots.txt`, a sitemap, and LocalBusiness, Service, FAQ, and breadcrumb schema
- A quote form that stays in the browser. The Google listing has no email, so the form does not pretend to send one

## What the Google listing did not have

Checked on 6 October 2026:

- No work photos. The photo button opens a street view of the road, which shows other people’s homes, so those frames are not copied onto this site. The contact page embeds the map instead.
- No opening hours
- No website link
- The listing was not shown as claimed

An older Electrotech website said the firm was NICEIC registered, with City & Guilds qualifications, TrustMark, the Bedford Borough Trading Standards scheme, and £2 million of public liability insurance. The site tells visitors to ask for current proof. Those badges are not shown as if they were checked today.

A website cannot by itself guarantee a number-one Google ranking. The pages are written for the real business, with consistent name, address, and phone details, so the technical side is ready to support the Google listing.
